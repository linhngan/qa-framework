## Known limits
- The interface side of the permissions is unverified: `/permissions`, the active mode, and whether allowed commands prompted (evidence/task10-note.md).
- Bash commands are covered neither by the guard nor by the Read/Edit rules. `cat`, `sed -i` or a heredoc can bypass both.
- The guard fails open on errors, and its CRITICAL list is kept by hand in three places (G8).
- Generated blocks have no edit protection. `npm run vault:check` and pre-push notice a hand edit or a stale block; nothing stops one being made.
- The link checker checks that files exist, not heading fragments or web links.
- Not yet seen live:
  - the note refresh inside the PostToolUse recorder (`--from-hook`), since no Claude edit of a spec has happened since it was added;
  - the session modes since the Task 11 change, since no session has started or ended;
  - the new pre-commit steps on a commit in this repository.

  All three are script-verified (evidence/task11-note.md).
- The generator supports only the syntax the current specs use: one level of `test.describe`, literal titles, `test.beforeEach` and `runIfEnv`. Anything else fails the run by design.
- Journals in `12-progress-report/` and today's changelog are not tracked in Git, so the map describes them without linking them.
- There is no CI. Git hooks run only where `npm install` activated them.
