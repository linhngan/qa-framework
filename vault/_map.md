# Vault map

Project notes kept next to the code. Only scripts/vault-sync.mjs writes to `_changelog/`.

- `_raw/` — unprocessed inputs. Empty for now; `.gitkeep` keeps the folder in Git.
- `_changelog/` — written by scripts/vault-sync.mjs:
  - `YYYY-MM-DD.md` — one line per Claude Code Edit or Write call on a project file outside `vault/`, named by local date. Not ignored by Git, so it is committed with the work.
  - `sessions.log` — one line per session start and one per session end. Ignored by Git (`*.log` in .gitignore).
- `03-framework/` — how the framework works, e.g. [hook-lifecycle-map.md](03-framework/hook-lifecycle-map.md).

## Tree

```
vault/
├── _map.md                 this map
├── _context.md             verified state, limits and next work
├── _raw/                   unprocessed inputs
├── _changelog/             written by scripts/vault-sync.mjs (edit log and sessions.log)
├── 03-framework/           guides
│   └── hook-lifecycle-map.md
├── 12-progress-report/     daily journals (/worklog); not tracked in Git yet
├── sources/jira/           imported Jira key map, only when the seed import writes one (none yet)
└── tests/                  one note per spec, generated by npm run vault:sync
    └── blog/
```
